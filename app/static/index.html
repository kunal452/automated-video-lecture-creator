🚀 Deploy LecturaFlow Live

LecturaFlow runs on a zero-cost stack using FastAPI, Edge-TTS, and ImageIO-FFmpeg. You can deploy it to any cloud host in under 3 minutes!

🌐 Render.com

Uses the included render.yaml blueprint with automatic HTTPS.

Build: pip install -r requirements.txt Start: uvicorn app.main:app --host 0.0.0.0 --port $PORT

🐳 Docker / VPS

Run on any Ubuntu, Debian, or EC2 instance using the included Dockerfile.

docker build -t lecturaflow . docker run -p 8000:8000 lecturaflow
